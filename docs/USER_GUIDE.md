# User Guide

## At the machine (phone)

1. Tap the **camera button** (bottom center) to start a **New visit**.
2. Type the **Machine ID** (e.g. `SNB7412`). The app shows the name this visit will get:
   - new machine → `SNB7412`
   - machine already visited → `SNB7412_01`, `SNB7412_02`… along with the date and call type of the last visit
3. Choose **ATM** or **Card / Statement Printer** (remembered per machine), the **call type** (PM, INSTALL, FLM, CHGF, CHGC, NORMAL, INSPECTION, ESCALATION…), the date and an optional ticket number. Tap **Start visit & capture**.
4. Capture evidence:
   - **Take photo**: opens the phone camera, one photo per tap
   - **Live multi-shot**: an in-app camera; tap the shutter repeatedly, then **Done**
   - **From gallery**: pick photos you already took
   - **Scan document**: pick the type first (442 Form, PM Checklist, Service Report…), then shoot the paper. It is enhanced for readability.
   - **Doc file / PDF**: attach a PDF or image file
   - Set **Tag new photos** (Before / After / Serial / Error…) before shooting if you want the photos labelled
5. The bar at the top shows **x / required photos** (the company rule set in Settings).
6. Tap **Save & ZIP**, then **Share…** to send the package straight to your manager. Saving is automatic; the ZIP is only needed when you want to send something.

## Import from the phone gallery

- **More → Import → Pick photos**, or in Google Photos select photos → **Share → CE Smart Evidence**.
- Photos are grouped by the **date they were taken**. For each group, enter the machine ID and call type, then tap **Create visit & import**. You can also use **Add to existing visit…**.

## Organising

- **Files** shows case folders: Regular · Inspection · Escalation · Follow-up · For Review · Closed. Each folder is split into ATM and Card Printer.
- Tick visits → **Move to folder…**, **ZIP** or **Delete**. On the laptop, you can also **drag a visit onto a folder tab**.
- Inside a visit, tick photos → **Move to visit** (they are renamed automatically), **Tag**, or **Delete**.
- **Machines** lists the ATM and Card Printer registries separately. Each machine has a full visit timeline and "next visit name".

## Finding things

- The search box at the top of every screen accepts machine ID, visit name, ticket, branch, remark or file name.
- **Search** adds filters for machine type, call type, folder, review state, date range and "below required photos". You can **ZIP results**.

## Daily justification

- **Daily log** shows how many **ATM machines** and **card printers** you visited each day, with photo and document counts and call types.
- The monthly calendar shows ATM / CP counts per day. The table gives month totals (unique machines and visits). **Excel** exports it.

## Reports for management

**Reports** → choose a period (Today, 7 days, This month, Last month…) and the machine type, then pick a format:
- **HTML**: one web page with KPIs, charts, tables and sample photos
- **PDF**: A4 landscape, ready to print
- **PowerPoint**: title, KPIs, editable charts, daily table, top machines, compliance, photo slides
- **Excel**: Summary, Daily, Visits, Files, Call types and Machines sheets
- **Evidence ZIP**: every photo and document in the period, foldered by type/machine/visit, with `preview.html`

## Management review

- Open a visit → **Review** for a full-screen viewer (arrow keys or swipe, double-click to zoom, ▶ slideshow, ⬇ original).
- **Management review** panel: Pending / Approved / Needs rework, plus a note. The dashboard lists visits needing attention.
- Turn on **Review mode** in Settings when presenting, so editing buttons are hidden.

## Good habits

- Sync (cloud icon) before starting a visit on a second device.
- Export a **full backup** monthly (Settings → Data & storage).
- Keep the required photo count in Settings in line with the company rule. The dashboard compliance percentage depends on it.
